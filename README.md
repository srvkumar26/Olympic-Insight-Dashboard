Olympic Insights Dashboard

Project Overview

This Power BI dashboard was developed as part of the Olympic Insights Dashboard case study. The project analyzes 120 years of Olympic history (1896–2016) to help decision-makers understand historical trends, country performance, athlete achievements, sports performance, and medal distribution through interactive visualizations.

Business Problem

The objective is to provide an executive dashboard that enables users to answer key business questions, such as:

Which countries have dominated the Olympic Games?
How has Olympic participation evolved over time?
Which sports have contributed the most medals?
Who are the most successful Olympic athletes?
How has gender participation changed over the years?
Do host countries perform better in their home Olympics?

This dashboard provides executives with an interactive view of Olympic history, helping them identify trends, compare country performance, evaluate athlete achievements, and gain meaningful insights from over a century of Olympic data.
